# 將 AI Benchmark 專案封裝為具備數據合約的自訂容器並透過 ACR 部署

在本快速入門中，您將學習如何將 GitHub 上的開源或私有 AI Benchmark 專案封裝為 Docker 容器，並將其推送到 Azure Container Registry (ACR)。為了解決跨部門部署的信任與資安問題，此容器將內建數據合約（Data Contract）定期授權金鑰機制，供各種本地 Edge 設備（包含但不限於各品牌之 NPU/GPU 邊緣節點）安全拉取與運行。

### 軟體需求 (Prerequisites)

* 具有有效訂用帳戶的 Azure 帳戶。 免費建立帳戶。
* 本地端已安裝 Docker Engine。
* 本地端已安裝 Azure CLI (版本 2.0.80 或更新版本)。
* 熟悉基本的終端機（CLI）操作與 Python 虛擬環境。
